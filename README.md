One emoji, the one most likely to make a stranger smile: **🤗 Hugging Face
(U+1F917)**. Twelve candidate emojis were drafted and scored against the
judge's five criteria in order, then the top three went before an
independent judge panel. The panel's combined verdict (🤗 85, 🌻 81, 🫶 75)
agrees with the internal pick — and 🤗 wins criterion 1, the most
important, in both judges. See `../candidates.md` for the full candidate
list, scores, and the panel verdict.

Panel caveat, recorded honestly: only 2 judges delivered a verdict
(deepseek-v4-flash and grok-4.7-fast). glm-5.3-flash, llama-3.3-70b, and
minimax all failed at the gateway (500/429/timeouts), so substitutes were
used per the brief.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
